Formula sheet — Denis writes this from memory every day

Cost statement
Direct material
+ Direct labour
+ Direct expenses (e.g. designer fee)
= PRIME COST
+ Production overhead
= PRODUCTION COST
+ Other overhead (= period cost)
= TOTAL COST
Material — FIFO / AVCO
FIFO: oldest layers leave first; closing stock = newest prices
Weighted AVCO = total cost ÷ total units
Simple AVCO = sum of prices ÷ number of prices
DM cost = rate × units issued
LIFO = banned under IFRS/IAS
Traditional overhead
OH rate = total production OH ÷ total driver units (labour hrs or machine hrs)
OH per unit = OH rate × hours per unit
Unit production cost = DM + DL + OH per unit
ABC — two stages
1. Pool: overhead → activities
2. Driver rate = activity cost ÷ total driver volume
OH to product = Σ (driver rate × driver units the product consumed)
Check: products add back to the pool total
Variance
Variance = actual − budget
% = variance ÷ budget
Revenue below budget = unfavourable
Cost above budget = unfavourable
Apportionment drivers
Rent, insurance, cleaning → floor area
Canteen, supervisor salary → headcount
Machine depreciation → machinery value
Machine maintenance → number of call-outs
